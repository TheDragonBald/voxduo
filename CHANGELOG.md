# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [семантическому версионированию](https://semver.org/lang/ru/).

## [Не выпущено]

### Добавлено

- Распознавание речи на faster-whisper с выбором между `large-v3` и
  `large-v3-turbo`, автоматическим выбором видеокарты или процессора
- Синтез речи тремя движками — edge-tts, Silero, Piper — с автоматическим
  переключением на следующий доступный, если основной не справился
- Интерфейс на CustomTkinter: два режима в одном окне, светлая и тёмная темы
- История последних пяти записей в каждом режиме, переживает перезапуск;
  озвучки переслушиваются без повторного синтеза
- Подтверждение копирования тремя сигналами: всплывающая плашка, смена вида
  кнопки и подсветка поля
- Настройки: микрофон, подсказка для Whisper, словарь замен, версия Edge
- Журнал с ротацией и перехватом исключений из фоновых потоков; тексты
  расшифровок в журнал не пишутся
- Сводка об окружении по `python -m voxduo --check`
- `install.ps1` — установка с автоматическим определением видеокарты
- `justfile` — команды проекта
- Сборка `voxduo.exe` для запуска без Python: GitHub Actions собирает её по
  тегу и прикладывает к релизу
- Еженедельная проверка edge-tts в CI: если синтез перестанет отвечать,
  заводится issue

### Изменено

- Зависимости переехали с четырёх `requirements*.txt` на `pyproject.toml`
  и `uv.lock`: точные версии всего дерева, а не только прямых пакетов, и
  одинаковое окружение у разработки, CI и сборки `.exe`
- Проект переписан из одного файла `voice_to_text.py` в пакет; исходный
  скрипт сохранён в `legacy/` как отправная точка
- `openai-whisper` заменён на `faster-whisper`: те же веса, кратно быстрее,
  встроенный фильтр тишины
- Модель по умолчанию — `large-v3` вместо `small`

### Исправлено

- Ошибки в фоновых потоках больше не теряются: раньше при запуске без
  консоли `print` уходил в никуда, и окно молча зависало на статусе
  «Обработка…»
- Тишина и паузы не превращаются в выдуманные фразы вроде «Продолжение
  следует…» — включён фильтр речевой активности
- Английские термины в русской речи чаще остаются латиницей
